# PriorityRing (2026)

A high-reliability emergency bypass system for parents.

## Architecture
- **Framework:** Flutter (Mobile + Web)
- **Pattern:** Feature-First Clean Architecture
- **Backend:** n8n (Regional Silos: EU, India, US)
- **Reliability:** Local Bypass (2x Call) + n8n Gatekeeper (SMS verification)

## Compliance
- **EU:** GDPR (Hetzner Frankfurt)
- **India:** DPDP (AWS Mumbai)
- **US:** CCPA (AWS Virginia)
